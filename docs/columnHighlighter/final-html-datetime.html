About this example

Demonstrates type: 'date' comparisons on an HTML DataTable. Each column uses a different input format (including common PowerShell/.NET style formats) while using the same threshold date.

Configuration (rules excerpt)

var threshold = { year: 2025, month: 1, day: 5, hours: 0, minutes: 0, seconds: 0 };

columnHighlighter: {
  rules: [
    {
      conditionsContainer: [
        {
          logic: 'AND',
          conditions: [
            {
              columnName: 'EU Slash',
              operator: 'lt',
              type: 'date',
              valueDate: threshold,
              dateTimeFormat: 'dd/MM/YYYY HH:mm:ss'
            }
          ]
        }
      ],
      targets: [
        { column: 'EU Slash', css: { 'background-color': '#ffdddd', color: '#000' } }
      ]
    }
  ]
}
