# HTMLExtensions examples

HTMLExtensions provides JavaScript and CSS helpers for DataTables, including column highlighting, search highlighting, and responsive or scroll view toggling. This site contains interactive examples. The project README describes installation and supported options.

- [Project README](https://github.com/EvotecIT/HTMLExtensions/blob/master/README.MD)
- [HTML table highlighting](https://htmlextensions.evotec.xyz/columnHighlighter/final-html-simple.html)
- [Conditional highlighting](https://htmlextensions.evotec.xyz/columnHighlighter/final-html-and.html)
- [Advanced highlighting](https://htmlextensions.evotec.xyz/columnHighlighter/final-html-advanced.html)
- [All examples](https://htmlextensions.evotec.xyz/)

Examples use demonstration data. Their values are not product or service measurements.
